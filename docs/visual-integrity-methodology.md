# Visual Integrity methodology

Visual findings require rendered evidence. A finding must retain URL, screenshot reference, viewport, timestamp, selector where available, source layer, and confidence.

Permitted findings include confirmed broken images, unreadable overlays, clipping, overlap, mobile overflow, contrast problems, placeholder imagery, and visibly broken counters. File names, image format, raw HTML, or CSS alone do not prove a visual defect. If rendering is unavailable, use RENDERING_REQUIRED or UNVERIFIED rather than a negative claim.
