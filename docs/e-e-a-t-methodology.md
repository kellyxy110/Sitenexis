# E-E-A-T methodology

E-E-A-T is an evidence view over existing SiteNexis modules, not a replacement trust engine.

| Dimension | Evidence | Existing modules | Limits |
| --- | --- | --- | --- |
| Experience | named projects, outcomes, dates, first-party implementation evidence | Information Gain, content, Scout | absence in a sample is not proof of no experience |
| Expertise | biographies, qualifications, technical explanation, authorship | Entity Intelligence, schema, content | credentials require validation where material |
| Authoritativeness | independent mentions, professional bodies, partnerships, original research | Citation Intelligence, Entity Authenticity | no backlink provider means authority totals are partial |
| Trustworthiness | legal identity, contacts, policies, security, consistency | Machine Trust, security, governance, entity consistency | no visible badge is security proof |

V2 reports each dimension separately, records source layers, and uses commercial-risk context to set evidence expectations. It does not label a site YMYL by default and does not create another independent trust score.
