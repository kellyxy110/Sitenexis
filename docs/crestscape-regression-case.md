# Crestscape regression case

Crestscape International is a regression fixture, not a production rule or required-score template. Future tests must validate evidence handling and language, including:

- robots retrieval success versus a timeout;
- sitemap index, child sitemaps, and custom template/form/user sitemap classification;
- raw versus rendered heading differences;
- entity-name and email variations with both values retained;
- a malformed borehole URL as URL-level evidence;
- zero counters distinguished from rendering failure or placeholder evidence;
- local evidence and founder versus official-company profile classification;
- external citation uncertainty and backlink-provider unavailability;
- performance claims only when measurements exist;
- no decline conclusion without comparable history.

The fixture must not prescribe an overall score. It must test reasoning, source layer, coverage, confidence, and recommendation wording.
