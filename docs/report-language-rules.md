# Report language rules

## Required distinction

Every material statement must state whether it is confirmed, suggested, unavailable, conflicting, historical, or recommended.

| Do not say | Use instead |
| --- | --- |
| “The site has no backlinks.” | “No strong independent backlinks were found in the sampled sources. Complete backlink metrics require a connected provider.” |
| “The site is declining.” | “Historical visibility data is unavailable, so no trend conclusion was generated.” |
| “The website has no schema.” | “No structured data was detected in the sampled raw or rendered pages.” |
| “The page has no H1.” | “No H1 was detected in the static response; rendered validation is required.” |

Use “sources disagree” for conflicts, “coverage is partial” for incomplete samples, “temporarily unavailable” for timeouts, “detected after rendering” for rendered-only evidence, and “requires external data” for provider gaps. Low-confidence findings must use conditional language and cannot support a categorical business-risk claim.
