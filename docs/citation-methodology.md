# Citation methodology

## Citation Readiness versus Citation Authority

Citation Readiness is on-site: factual density, stable URLs, authorship, methodology, evidence, definitions, first-party experience, and freshness. Citation Authority is off-site: independent mentions, directories, professional bodies, partners, media, connected Search Console data, and verified backlink providers.

| Provider tier | Use | Limit |
| --- | --- | --- |
| Connected provider or Search Console | verified metrics and observed data | scope remains provider-specific |
| Verified external profile/directory/review | corroboration | not a full backlink index |
| Search sampling | qualitative sampled evidence | absence does not prove zero |
| No provider | no totals | report PROVIDER_UNAVAILABLE or EXTERNAL_DATA_REQUIRED |

Never state that a site has no backlinks from search-result absence. Use: “No strong independent backlinks were found in the sampled sources. Complete backlink metrics require a connected provider.”
