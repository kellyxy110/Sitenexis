# Citation Intelligence™ — Free-First Operating Model

## Product boundary

The free SiteNexis experience does not depend on a paid backlink index, commercial mention database, or commercial AI-monitoring provider.

The core modules are:

- Internal Link Intelligence
- Citation Intelligence
- Entity Intelligence
- Trust Intelligence
- Retrieval Intelligence
- Authority Flow
- Link Graph Analysis
- Controlled Retrieval Simulation

Optional future modules are explicitly separate:

- External Backlink Intelligence
- Brand Mention Intelligence
- Competitor Link Intelligence

The optional modules may consume a provider later, but their absence must not disable the core audit.

## State model

The result contract separates execution, evidence and provider availability:

| Field/state | Meaning |
|---|---|
| `completed` + `available_with_evidence` | The core analysis ran and found evidence. |
| `completed` + `available_no_evidence` | The core analysis ran, pages were available, and no relevant signal was observed. |
| `completed` + `partially_available` | The free core ran and found evidence, but external coverage is not enabled. |
| `no_data` + `unavailable` | No crawled pages were available; no score is returned. |
| `failed` + `failed` | Collection or validation failed; no score is substituted. |

`providerState` is independently `not_configured` for the current free core. This prevents “external data unavailable” from being confused with “no evidence found.”

## Evidence hierarchy

Every finding carries its evidence source:

1. `first_party_crawl` — links, headings, schema, canonical URLs, robots directives and page content observed by SiteNexis.
2. `structured_data` — JSON-LD, Open Graph, sameAs and other machine-readable resources found during the crawl.
3. `google_authorized` — data returned for a user-authorized GA4 or Search Console connection.
4. `retrieval_simulation` — reproducible SiteNexis retrieval tests and their inputs/outputs.
5. `provider` — an optional external adapter, only when explicitly enabled and available.

“Not observed” and “not available” are different states. Missing provider data must never be converted into a zero backlink count or a zero authority score.

## Free-core implementation

The Citation Intelligence analyzer uses the completed crawl to measure:

- internal citations and inbound coverage;
- outbound reference categories;
- sameAs and entity references;
- structured data coverage;
- evidence density;
- source diversity observed in the site corpus;
- orphan pages and internal citation gaps;
- deterministic authority, trust, entity and retrieval-readiness estimates.

These measures describe the audited site and its observable evidence. They do not claim to be a web-scale backlink index.

## Backlink boundary

The free core must use the following language:

- “External backlinks: unavailable from the current crawl.”
- “Unlinked mentions: unavailable without an external discovery source.”
- “No backlink data was imported.”

It must not say “0 backlinks” unless a source actually returned a verified zero result. The current Google Search Console API integration provides Search Analytics data, not a repository implementation of the Search Console Links report. Therefore SiteNexis must not imply that connected Search Console currently supplies complete backlink counts.

## AI Citation Intelligence

The free core evaluates whether content is understandable, retrievable and citation-ready using:

- existing retrieval simulation;
- citation-probability factors;
- entity extraction and consistency;
- evidence density and specificity;
- structured data and source attribution;
- deterministic chunk and answer-readiness checks.

These are readiness and reproducibility measurements. They are not claims about every answer generated by every AI system.

## Score model

All Citation Intelligence scores are deterministic 0–100 estimates based on observed first-party crawl evidence. Optional external signals are not included in the free-core formulas.

### Citation Readiness

The current Citation Intelligence score is:

`0.45 × evidenceDensity + 0.30 × internalCoverage + 0.25 × entityScore`

- `evidenceDensity = min(100, externalReferences/pages × 25 + sourceCategories × 10 + sameAsReferences × 8)`.
- `internalCoverage = (pages − orphanPages) / pages × 100`.
- `entityScore = clamp((sameAs exists ? 55 : 25) + min(30, sameAsReferences × 10) + structuredDataPageRatio × 15)`.
- Source: SiteNexis crawl, outbound reference analysis, structured data and internal link graph.
- Missing data: no pages returns `null`; unavailable external coverage is reported as a limitation and does not become zero.
- Confidence: `0.82` for a completed crawl-only snapshot; `0` for no data.
- Evidence count: `counts.signals`, with component counts for internal, external and sameAs evidence.
- Limitation: this is citation readiness, not observed AI citation frequency or a backlink count.

### Authority Flow

Authority Flow is provided by the existing internal link graph, not by external backlink authority. Its page-level formula is:

`0.40 × normalizedPageRank + 0.30 × inboundRatio + 0.20 × depthScore + 0.10`

The site-wide value is the PageRank-weighted average of page Authority Flow scores. PageRank uses a damping factor of `0.85` and ten iterations. Source: crawled internal links. Missing data: an empty graph returns the existing unavailable/zero structural result and must be presented as no graph data, not as no external authority.

### Trust

Trust is the existing Semantic Trust score. It combines authorship, organisational, content and structural trust analyzers, including author/organization signals, contact and policy signals, factual consistency, dates, schema and citations to authoritative sources. The final score is the bounded aggregate returned by `analyzeSemanticTrust()`. Source: crawl content, schema and page metadata. Missing data: an empty crawl returns no meaningful trust evidence; provider absence does not reduce the score.

### Retrieval Readiness

Retrieval Readiness is the existing AI Readability score: the average of per-page 0–100 totals across entity clarity, conversational readiness, AI extractability and knowledge-graph structure. Source: crawled page text, headings, structure and schema. Missing data: pages with unavailable AI scoring are excluded from dimension averages; no scored pages returns the analyzer’s no-data result. It does not claim observed retrieval by a commercial AI system.

### Entity Confidence

Entity Confidence is the existing Entity Intelligence report score, built from entity consistency, coverage and disambiguation. Consistency averages entity-level scores starting at 100 and deducting 20 for conflicting types and 15 for materially different descriptions. Coverage uses entity count and page coverage, with penalties when most entities occur on only one page. Disambiguation starts at 100 and deducts for low sameAs coverage and generic ambiguous names. Source: entity extraction from crawled content and structured data. Missing data: no entity map is reported as a low-coverage finding and is not presented as proof that the web has no entities.

## Provenance requirements

Every result exposes:

- `generatedAt`;
- confidence;
- evidence count;
- `providerState`;
- readable provenance labels;
- limitations.

The dashboard identifies current evidence as SiteNexis crawl, structured data, sameAs analysis, internal link graph and outbound reference analysis. Google-authorized data and retrieval simulation must be labeled separately when included by another module.

## Optional adapter contract

Future adapters should implement a common contract with:

- provider name and version;
- tenant/user scope;
- request and response timestamps;
- source and target URLs;
- signal type;
- confidence;
- provenance;
- quota and rate-limit state;
- raw evidence reference without exposing credentials;
- explicit `not_configured`, `no_data`, `partial`, and `failed` states.

The repository contract is defined in `packages/analyzers/src/citation-intelligence/provider.ts`. No paid adapter is instantiated by the free core.

An adapter may enrich a report but may not replace the free-core result or silently alter its meaning.

## Existing exception

The repository contains an existing optional Serper integration for the Information Gain Engine. It is not a dependency of the free-core Citation Intelligence analyzer. It remains provider-gated and must continue to degrade truthfully when `SERPER_API_KEY` is absent.

## Product naming

“Citation Intelligence” is appropriate for the free core because it describes references, evidence, entity clarity and citation readiness. “Backlink Intelligence” should be reserved for an explicitly enhanced module that has an actual external backlink source. The free core should use “Internal Link Intelligence,” “Authority Flow,” and “External Evidence Coverage” where those are the actual measurements.

## Remaining risks

- Production Vercel environment values and GTM container configuration still require external verification.
- Google-authorized data is available only after the user connects GA4/Search Console; it is not assumed.
- Full external backlink and unlinked-mention discovery remains intentionally outside the free core.
- Retrieval Simulation estimates reproducible readiness; it does not prove citation by a particular AI provider.
- Optional provider adapters have a contract but no enabled commercial implementation, by design.
